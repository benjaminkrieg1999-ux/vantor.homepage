Einrichten
  1. Gmail: Einstellungen → Alle Einstellungen → Signatur → Neu → einfügen → Speichern.
  2. Outlook: Einstellungen → Konten → Signaturen → einfügen → Speichern.
  3. Apple Mail: Einstellungen → Signaturen → + → „Immer mit Standardschrift“ aus → einfügen.
  4. iPhone: Signatur in Apple Mail am Mac einrichten oder per Mail an dich schicken, dann unter Einstellungen → Mail → Signatur einfügen.
